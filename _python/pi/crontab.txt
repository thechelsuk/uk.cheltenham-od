# The Pi's crontab. Install or update it with:
#
#   crontab ~/uk.cheltenham-od/_python/pi/crontab.txt
#
# Times are UK time: the Pi's clock is on Europe/London, and the watchdog
# reads its copy of these schedules the same way. The dispatch lines start the site's
# scheduled GitHub workflows; they must match
# cloudflare/pi-watchdog/src/schedules.js (a test checks), which the Cloudflare
# watchdog uses to start any that fall due while the Pi is down.

LOG=/home/mat/uk.cheltenham-od/run.log
PI=/home/mat/uk.cheltenham-od/_python

# Data scripts: the lists in every-5-minutes.txt and hourly.txt. They share a
# lock so two runs never pull, commit or push at once.
*/5 * * * *  /usr/bin/flock -n /tmp/chelt-od.lock $PI/run.sh every-5-minutes >> $LOG 2>&1
3 * * * *    /usr/bin/flock -w 300 /tmp/chelt-od.lock $PI/run.sh hourly >> $LOG 2>&1
