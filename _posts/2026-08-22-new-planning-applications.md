Cheltenham Open Data has added a [local list of Cheltenham's planning applications](/cheltenham-planning-applications).

Cheltenham Borough Council's planning portal is checked frequently and any changes are shown on the site as they are published.

The list covers new build housing, extensions, listed building consents, tree works, and change of use applications submitted across the borough. Each entry shows the application reference, address, postcode, current status, and a link back to the council's own planning file for full documents and plans.

Applications are tracked for six months from their received date, so the list reflects what's currently live or recently decided rather than the full historical archive. For anything older, the council's PublicAccess portal remains the definitive source.
