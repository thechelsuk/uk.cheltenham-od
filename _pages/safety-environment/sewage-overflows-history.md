## Sewage Spill History

Each time a storm overflow near Cheltenham stops discharging, the spill is added to this log with when it started, when it ended and how long it lasted. The tables show how many spills each month and each watercourse has had, and the total hours of discharge.

The log only records what has happened since it began, plus the most recent spill at each overflow before then, so it is not a full archive. For what is happening now, see the [live sewage overflow status](/cheltenham-sewage-overflows).
