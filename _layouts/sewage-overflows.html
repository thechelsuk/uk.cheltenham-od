What Is a Storm Overflow?

  • A release point that lets the sewer network discharge diluted wastewater into a river during heavy rain, so that sewers don't back up into homes and streets. An Event Duration Monitor records when each one starts and stops.

Can I See Past Spills?

  • Yes. The sewage spill history logs every spill since logging began, with monthly totals for each river and brook.
