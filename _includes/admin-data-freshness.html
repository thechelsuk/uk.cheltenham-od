When each source's data file last changed, from the date of the last git commit that touched it, against how long its schedule allows: 2 days for data checked every 5 minutes, hourly or every two hours, 4 days for daily and 45 days for monthly. Scheduled fetchers fail quietly (the workflows carry on past an error), so:

  • Stale: the file records a date on every run, so no change means the fetcher hasn't succeeded. Worth a look.
  • Unchanged: the file only changes when its data does (a plain list or a raw feed), so it may be healthy with nothing new. Check the source if it seems too long.
  • Manual: refreshed by hand, never flagged.

Files and schedules are listed per source in _data/sources.json.
